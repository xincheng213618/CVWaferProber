# CVWaferProber 代码结构总览

## 1. 项目概述

CVWaferProber 是一个基于 **WPF (Windows Presentation Foundation)** 的晶圆探针台自动化测试系统。采用 **.NET 8.0** 框架，使用 **MVVM** 架构模式，支持多种测试流程（IVL、EQE、AOI、VAM），集成了光谱仪控制、相机图像处理、晶圆映射可视化等功能。

- **公司**: ColorVision
- **版本**: 2026.03.13.0
- **目标框架**: net8.0-windows
- **UI 框架**: WPF + AvalonDock (多面板布局)

### 4.4 WaferProberClient (通信层)

| 子项目 | 文件数 | 总行数 | 说明 |
|--------|--------|--------|------|
| WaferComm.Core | 3 | ~300 | 接口、模型、事件定义 |
| WaferComm.Client | 2 | ~450 | TCP客户端（$CMD#协议） |
| WaferComm.Processors | 3 | ~400 | 响应解析处理器 |
| WaferComm.StateMachine | 5 | ~2,500 | 状态机、运动/加热监控 |

**通信协议**: `$<命令代码><参数>#`
- `$G0X100Y50#` — 绝对移动到 X100, Y50
- `$G1X10Y5#` — 相对移动 (+10, +5)
- `$T180#` — 设置温度 180°C
- `$Z01#` / `$Z00#` — Z轴下/上
- `$$67#` — 到达信号（完成移动）

**状态机** (ProberStateMachine, 802行):
```
Disconnected → Connected → Ready → WaitingForWafer
→ WaferLoaded → Aligning → Testing ⇄ Paused
→ Stopping → Stoped | Error | Maintenance
```
