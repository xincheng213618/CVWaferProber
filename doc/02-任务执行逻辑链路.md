
## 3. 手动测试执行链路

```
用户操作: 在芯片映射视图中选择一个芯片 → 点击"手动测试"

┌─────────────────────────────────────────────────────────────────┐
│ 步骤 1: 用户选择芯片                                              │
│ ChipMappingControl                                              │
│  └── ChipViewModel.Selected = true                              │
│      └── 通知 MappingDataViewModel.SelectedChip 更新             │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 2: 开始手动测试                                              │
│ MainViewModel.StartManTest()                                    │
│  ├── 1. 检查探针台连接状态                                        │
│  ├── 2. 获取选中芯片的坐标 (X, Y)                                │
│  ├── 3. 更新芯片状态为 TESTING                                   │
│  └── 4. 调用 ProberClientService                                │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 3: 探针台移动                                                │
│ ProberClientService                                             │
│  ├── WaferProberTCPClient.MoveAbsoluteAsync(X, Y)              │
│  │   └── 发送 TCP 命令: "$G0X{x}Y{y}#"                         │
│  ├── 等待到达信号 "$$67#"（超时60秒）                             │
│  │   └── MotionMonitor 监控 XY 运动完成                          │
│  ├── Z轴下降（接触晶圆）                                         │
│  │   └── 发送: "$Z01#"                                          │
│  └── 状态: ProberState → Testing                                │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 4: 激活测试面板                                              │
│ MainService                                                     │
│  ├── 根据当前测试流程选择面板                                      │
│  │   ├── IVL → 切换到光谱仪面板                                  │
│  │   ├── AOI → 切换到相机面板                                    │
│  │   ├── EQE → 切换到光谱仪面板                                  │
│  │   └── VAM → 切换到相机面板                                    │
│  └── 调用 MainViewModel Action 委托切换 AvalonDock 标签          │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 5: MQTT 测试请求                                            │
│ FlowMQTTService                                                 │
│  ├── 构建测试请求消息 (JSON)                                      │
│  │   ├── FlowId, DeviceCode, Parameters                        │
│  │   └── 发布到 MQTT Topic: Flow/{nodeName}                     │
│  ├── 等待测试结果（可配置超时 120秒）                               │
│  │   └── 订阅: STATUS topic 等待结果                              │
│  └── 接收结果 → FlowCompletedEvent                              │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 6: 实时数据更新（测试执行中）                                   │
│ CVSpectrumViewModel / CVEQEViewModel                            │
│  ├── 350ms 定时器循环刷新图表                                     │
│  │   ├── 更新 IV 曲线 (电流-电压)                                 │
│  │   ├── 更新 IL 曲线 (电流-亮度)                                 │
│  │   ├── 更新 VL 曲线 (电压-亮度)                                 │
│  │   ├── 更新光谱图                                              │
│  │   └── 更新 EQE 曲线                                          │
│  └── 数据来源: MQTT STATUS topic 实时推送                         │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 步骤 7: 测试完成处理                                              │
│ MainService.OnFlowCompleted()                                   │
│  ├── 1. 解析测试结果 (PASS/FAIL)                                 │
│  ├── 2. 更新芯片状态                                             │
│  │   ├── OK → ChipStatus.OK (绿色)                              │
│  │   ├── NG → ChipStatus.AOI_NG / DW_NG 等 (红色)              │
│  │   └── TIMEOUT → ChipStatus.OVERTIME (灰色)                   │

│  ├── 4. CSV数据导出（每个芯片一条记录）                             │
│  ├── 5. 数据库持久化                                             │
│  └── 6. 更新UI显示                                              │
└─────────────────────────────────────────────────────────────────┘
```

## 4. 批量自动测试执行链路

```
用户操作: 选择多个芯片 → 点击"自动测试"

┌─────────────────────────────────────────────────────────────────┐
│ 阶段 1: 初始化批量测试                                            │
│ MainViewModel.StartAutoTesting()                                │
│  ├── 1. 收集所有选中的芯片列表                                    │
│  ├── 2. 创建 AutoTestingItem（测试队列）                         │
│  ├── 3. 设置断点保存（每测一个芯片保存进度）                        │
│  ├── 4. 初始化 Summary.csv                                      │
│  └── 5. 开始递归测试: DoNextDieFlowExec()                        │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 阶段 2: 递归测试循环                                              │
│ DoNextDieFlowExec()                                             │
│  ├── 取出队列中下一个芯片                                         │
│  ├── 如果队列为空 → 测试完成，跳转阶段5                            │
│  ├── 如果不为空:                                                 │
│  │   ├── 更新当前芯片状态为 TESTING                               │
│  │   ├── 调用 ProberClientService 移动探针                       │
│  │   ├── 等待到达 + Z轴下降                                      │
│  │   ├── 执行测试流程（同手动测试步骤4-6）                         │
│  │   ├── 接收结果                                                │
│  │   ├── 检查 BreakOnError                                      │
│  │   │   ├── 如果失败且启用 BreakOnError → 暂停，等待用户确认    │
│  │   │   └── 否则继续                                            │
│  │   ├── Z轴上升                                                │
│  │   ├── 保存断点（当前进度）                                     │
│  │   ├── 更新 Summary.csv                                       │
│  │   └── 递归调用 DoNextDieFlowExec()  ← 处理下一个              │
│  └──────────────────────────────────────────────────────────────│
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 阶段 3: 多流程测试（单个芯片可能有多个流程）                        │
│                                                                 │
│ 每个芯片的测试流程链:                                             │
│ ┌─────┐   ┌─────┐   ┌─────┐   ┌─────┐                         │
│ │ AOI │ → │ IVL │ → │ EQE │ → │ VAM │                         │
│ └─────┘   └─────┘   └─────┘   └─────┘                         │
│                                                                 │
│ 流程执行顺序由数据库配置决定:                                      │
│ WaferProberDBService.InitBuzWaferProber_10001()                 │
│  ├── 加载流程定义（AOI: 120s, IVL: 120s, EQE: 120s, VAM: 120s）│
│  └── 按优先级顺序执行                                            │
│                                                                 │
│ 每个流程:                                                        │
│  ├── BaseService.Execute()                                      │
│  │   ├── FlowMQTTService.PublishRequest()                       │
│  │   ├── 等待 FlowCompletedEvent（超时可配置）                   │
│  │   └── 返回结果                                                │
│  └── 结果处理                                                    │
│      ├── PASS → 继续下一个流程                                   │
│      └── FAIL → 根据配置决定是否中断                              │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 阶段 4: 错误处理与恢复                                            │
│                                                                 │
│ BreakOnError 逻辑:                                              │
│  ├── 启用: 测试失败 → 暂停所有测试 → 弹窗询问用户                  │
│  │   ├── 用户选择"继续" → 跳过当前芯片，继续下一个                 │
│  │   ├── 用户选择"重试" → 重新测试当前芯片                        │
│  │   └── 用户选择"停止" → 保存断点，结束测试                      │
│  └── 禁用: 记录失败状态，自动继续下一个芯片                        │
│                                                                 │
│ 超时处理:                                                        │
│  ├── 单流程超时（默认120秒）→ 标记 OVERTIME                      │
│  ├── 运动超时（XY: 10秒, Z: 5秒）→ 状态机转 Error               │
│  └── MQTT响应超时 → 重试一次，再失败则标记                        │
│                                                                 │
│ 崩溃恢复:                                                        │
│  ├── 每测完一个芯片保存断点到本地文件                               │
│  ├── 应用重启时检测到未完成断点                                    │
│  └── 弹窗提示用户是否从断点处继续                                  │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 阶段 5: 测试完成                                                  │
│ MainService.OnAutoTestCompleted()                               │
│  ├── 1. 生成 Summary.csv（所有芯片测试汇总）                      │
│  ├── 2. 清除断点文件                                             │
│  ├── 3. 数据库持久化（Session 级别）                              │
│  ├── 4. 更新芯片映射视图（所有颜色状态刷新）                       │
│  ├── 5. Z轴上升至安全位置                                        │
│  ├── 6. 探针台状态: Testing → Ready                              │
│  └── 7. 弹窗提示"测试完成"                                       │
└─────────────────────────────────────────────────────────────────┘
```

## 5. MQTT 通信流程

```
┌──────────────────┐                    ┌──────────────────┐
│  CVWaferProber   │                    │  测试设备/服务     │
│  (MQTT Client)   │                    │  (MQTT Server)   │
└────────┬─────────┘                    └────────┬─────────┘
         │                                       │
         │  1. 注册节点                            │
         │  Topic: Regist/{nodeName}              │
         │──────────────────────────────────────→ │
         │                                       │
         │  2. 心跳维持                            │
         │  Topic: Heartbeat/{nodeName}           │
         │──────────────────────────────────────→ │
         │          (每30秒)                      │
         │                                       │
         │  3. 发送测试请求                        │
         │  Topic: Flow/{nodeName}                │
         │  Payload: {                            │
         │    "FlowId": "IVL_001",               │
         │    "DeviceCode": "DEV.SMU.Default",   │
         │    "Parameters": {...}                 │
         │  }                                    │
         │──────────────────────────────────────→ │
         │                                       │
         │  4. 接收实时数据推送                     │
         │  Topic: STATUS                         │
         │  Payload: {测量数据}                    │
         │ ←────────────────────────────────────  │
         │         (350ms间隔)                    │
         │                                       │
         │  5. 接收测试完成结果                     │
         │  Topic: STATUS                         │
         │  Payload: {                            │
         │    "Status": "Completed",             │
         │    "Result": "PASS/FAIL",             │
         │    "Data": {...}                      │
         │  }                                    │
         │ ←────────────────────────────────────  │
         │                                       │
```

```
         │                                       │

         │  到达信号                               │
         │  "$$67#"                               │

         │                                       │
         │  Z轴下降接触                            │
         │  "$Z01#"                               │
         │──────────────────────────────────────→ │
         │                                       │
         │  Z轴上升脱离                            │
         │  "$Z00#"                               │
         │──────────────────────────────────────→ │
         │                                       │

```

```
│                        数据产生                                   │

│  ├── 亮度数据 (Luminance, CIE_x, CIE_y)                        │
│  └── 图像数据 (Camera Bitmap)                                   │
├─────────────────────────────────────────────────────────────────┤
│                        数据处理                                   │
│  Service层                                                      │
│  ├── IVLService → SpectrumMeasurement 数据对象                  │
│  ├── EQEService → SpectrumEQEMeasurement 数据对象               │
│  ├── AOIService → AOI结果对象                                   │
│  └── VAMService → VAM结果对象                                   │
├─────────────────────────────────────────────────────────────────┤
│                        数据展示                                   │
│  ViewModel层                                                    │
│  ├── CVSpectrumViewModel → OxyPlot 图表模型                     │
│  │   ├── IV曲线 (IVPlotModel)                                  │

├─────────────────────────────────────────────────────────────────┤
```

## 9. 线程模型

```
┌─────────────────────────────────────────────────────────────────┐
│ UI线程 (Dispatcher Thread)                                      │
│  ├── WPF控件渲染                                                │
│  ├── 数据绑定更新                                               │
│  ├── 用户交互响应                                               │
│  └── 图表刷新 (350ms定时器通过Dispatcher回调)                    │
├─────────────────────────────────────────────────────────────────┤
│ TCP接收线程 (Background)                                        │
│  └── WaferProberTCPClient._stream.ReadAsync() 循环              │
│      └── 收到数据 → ResponseProcessor → EventAggregator.Publish │
├─────────────────────────────────────────────────────────────────┤
│ MQTT接收线程 (MQTTnet内部线程)                                   │
│  └── 消息到达 → FlowMQTTService 处理 → EventAggregator.Publish │
├─────────────────────────────────────────────────────────────────┤
│ 状态机线程 (ProberStateMachine)                                  │
│  └── _stateLock 保护状态转换 (lock)                              │
├─────────────────────────────────────────────────────────────────┤
│ 运动监控线程 (MotionMonitor)                                     │
│  └── 超时检测 (XY: 10s, Z: 5s)                                 │
├─────────────────────────────────────────────────────────────────┤
│ 温度监控线程 (HeaterMonitor)                                     │
│  └── 热平衡检测                                                 │
└─────────────────────────────────────────────────────────────────┘

线程安全机制:
├── _stateLock (状态机锁)
├── _moveLock (运动命令锁)  
├── Dispatcher.Invoke/BeginInvoke (UI线程回调)
├── ObservableCollection 只在UI线程操作
└── EventAggregator 线程安全发布/订阅
```
