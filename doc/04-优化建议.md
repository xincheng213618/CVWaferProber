## 阶段 1: 基础重构（代码健康）

### 1.1 提取图表 ViewModel 基类

**问题**: CVSpectrumViewModel 和 CVEQEViewModel 中有大量重复的图表初始化和更新逻辑。

**方案**: 创建 `ChartViewModelBase` 抽象基类，将共通的图表管理逻辑提取到基类中。

**具体步骤**:

```
1. 创建 ChartViewModelBase.cs
2. 将以下共通逻辑移入基类:
   ├── IV图表初始化/更新/颜色管理 (~150行)
   ├── VL图表初始化/更新/颜色管理 (~150行)
   ├── IL图表初始化/更新/颜色管理 (~150行)
   ├── Power_L图表初始化/更新/颜色管理 (~100行)
   ├── 公共属性定义（颜色、线宽、可见性等）
   └── ClearResult() 的共通逻辑
3. CVSpectrumViewModel 和 CVEQEViewModel 继承 ChartViewModelBase
4. 仅保留各自特有的逻辑
```

**示例代码**:


## 阶段 2: 性能优化

### 2.1 图表更新批处理

**问题**: 130+ 次 InvalidatePlot() 调用，每次属性变更都触发完整重绘。

**方案**: 引入批处理机制，将多次更新合并为一次。

**具体步骤**:

```csharp
// 新建: Utils/PlotUpdateBatcher.cs
public class PlotUpdateBatcher : IDisposable
{
    private readonly HashSet<PlotModel> _dirtyPlots = new();
    private readonly DispatcherTimer _timer;
    private bool _isBatchActive = false;

    public PlotUpdateBatcher()
    {
        _timer = new DispatcherTimer
        {
            Interval = TimeSpan.FromMilliseconds(50) // 50ms 合并窗口
        };
        _timer.Tick += FlushUpdates;
    }

    public void MarkDirty(PlotModel model)
    {
        _dirtyPlots.Add(model);
        if (!_isBatchActive)
        {
            _isBatchActive = true;
            _timer.Start();
        }
    }

    private void FlushUpdates(object sender, EventArgs e)
    {
        _timer.Stop();
        _isBatchActive = false;
        foreach (var model in _dirtyPlots)
        {
            model.InvalidatePlot(true);
        }
        _dirtyPlots.Clear();
    }

    public void Dispose() => _timer.Stop();
}

// 使用方式:
// 替换所有 model.InvalidatePlot(true) 为:
// _batcher.MarkDirty(model);
```

**预期效果**:
- 130+ 次刷新降至每 50ms 最多 1 次
- UI 响应速度提升 30-50%
- 多属性同时变更不会触发多次重绘

### 2.3 集合操作优化

**问题**: 频繁的 Clear() + 循环 Add() 操作触发大量 CollectionChanged 事件。

**方案**: 使用批量操作替代逐个添加。

**具体步骤**:

```csharp
// 方案 A: 使用 RangeObservableCollection
public class RangeObservableCollection<T> : ObservableCollection<T>
{
    private bool _suppressNotification = false;

    public void AddRange(IEnumerable<T> items)
    {
        _suppressNotification = true;
        foreach (var item in items)
            Add(item);
        _suppressNotification = false;
        OnCollectionChanged(new NotifyCollectionChangedEventArgs(
            NotifyCollectionChangedAction.Reset));
    }

    public void ReplaceAll(IEnumerable<T> items)
    {
        _suppressNotification = true;
        Clear();
        foreach (var item in items)
            Add(item);
        _suppressNotification = false;
        OnCollectionChanged(new NotifyCollectionChangedEventArgs(
            NotifyCollectionChangedAction.Reset));
    }

    protected override void OnCollectionChanged(NotifyCollectionChangedEventArgs e)
    {
        if (!_suppressNotification)
            base.OnCollectionChanged(e);
    }
}

// 使用方式:
// 替换 ObservableCollection<SpectrumMeasurement> 为 RangeObservableCollection
// 替换 foreach + Add 为 AddRange
```

**预期效果**:
- 减少 113+ 次 CollectionChanged 事件到最少次数
- 大数据量时 UI 刷新更流畅

### 2.4 异步数据加载

**问题**: 数据加载在 UI 线程执行，可能导致界面卡顿。

**方案**: 将数据处理移到后台线程。

```csharp
// 数据处理在后台线程
public async Task LoadMeasurementDataAsync(byte[] rawData)
{
    var measurement = await Task.Run(() =>
    {
        // 后台线程：解析数据、计算
        return ParseMeasurementData(rawData);
    });

    // UI线程：更新显示
    Application.Current.Dispatcher.Invoke(() =>
    {
        Measurements.Add(measurement);
        UpdateAllCharts(measurement);
    });
}
```

```csharp
// 图表更新添加异常处理
public void UpdatePlotSafely(PlotModel model, Action updateAction)
{
    try
    {
        updateAction?.Invoke();
        model?.InvalidatePlot(true);
    }
    catch (InvalidOperationException ex)
    {
        // 集合修改冲突
        Log.Warn($"Plot update conflict: {ex.Message}");
    }
    catch (Exception ex)
    {
        Log.Error($"Plot update failed: {ex.Message}", ex);
    }
}

// 数据验证
public bool ValidateMeasurement(MeasurementBase data)
{
    if (data == null) return false;
    if (data.Wavelengths == null || data.Wavelengths.Length == 0) return false;
    if (double.IsNaN(data.Voltage) || double.IsInfinity(data.Voltage)) return false;
    return true;
}
```
